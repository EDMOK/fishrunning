# 白饭大冲刺 · 商店与事件改造记录

日期：2026-09-26
状态：已实现，基础验证通过；长跑事件覆盖仍待补充

## 已确认需求

- 移除“正在同步”造成的视野遮挡，保留同步主题但改为不遮挡跑道的速度/间距影响。
- 移除固定里程三选一卡牌流程，改为 HUD 常驻商店按钮。
- 商店消费本局白饭，重新开始后清零；商店打开时冻结跑动，避免购买期间漏躲障碍。
- 普通技能直接升级，每项最多 3 级，价格 12 / 20 / 32 白饭。
- 随机折扣事件随机选择 1–2 项技能，六折，持续 12 秒；通过商店按钮主动购买。
- 特殊事件动态降频：前期稀疏，中后期逐渐加密，并避免连续同类事件。
- 增加维护闸门、滑动验证、请求排队、缓存未命中等阻碍/趣味事件，以及多段滑动走廊编排。
- 分区背景使用旧区淡出、新区淡入，避免硬切换。

## 技能

- 缓存命中：连击窗口每级 +0.3 秒。
- 滑动窗口：二段跳高度每级 +4%。
- 算力调度：道具持续时间每级 +8%。
- 白饭优化：白饭收益每级 +8%。

技能增益受等级上限约束，避免和事件倍率无限叠加。

## 实现边界

- 继续复用现有障碍素材和碰撞盒。
- 事件障碍放置前寻找空档，并调用现有审计逻辑；不新增未经验证的物理常量。
- 动态 UI 文案使用 `textContent`，不把事件内容拼入 HTML。
