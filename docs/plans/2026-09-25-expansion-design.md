# 白饭大冲刺 · 扩展设计（分区 / 事件 / 卡牌 / 里程碑）

日期：2026-09-25
状态：设计已实施；本文保留原始方案，实际实现与验证范围以同目录的实施记录为准。

## 目标

把一局无限跑酷从「一条背景跑到黑」扩展成**一条有叙事推进的赛道**：玩家沿距离依次经过五个
AI 圈的场所，途中触发取自真实行业事件的随机事件，并在里程碑处做一次构筑选择。

三条约束：

1. 现有的跳跃手感、碰撞盒、难度曲线**不动**。所有新系统只在外围加东西。
2. 新内容只从**可核实的事件**取材。查不到来源的说法一律不写进游戏。
3. 不新增必须联网或必须新生成的美术资产才能跑起来，缺图时优雅降级。

## 一、五个分区

沿距离切换，每区一套四层视差（sky / far / mid / ground）+ 一条区规（地段特性）。
分区背景已生成于 `assets/raw/zone_<id>_{sky,far,mid,ground}.png`。

| # | 区名 | 进入距离 | 现实原型 | 区规 |
|---|------|---------|---------|------|
| 0 | 语料海 | 0 | 现有赛博城市 | 无（教学区，沿用原生背景） |
| 1 | 榜单擂台 | 6000 | Benchmark 冲榜、LMArena 刷分 | 得分 ×1.25，障碍更密（gapMul 0.92） |
| 2 | 开源市集 | 14000 | 开源权重发布、HuggingFace | 白饭价值 ×2 |
| 3 | 算力金库 | 22000 | 算力囤积、Colossus、GPU 排队 | 道具时长 ×1.5，障碍略密 |
| 4 | 合规边境 | 32000 | 地区限制、出口管制、授权审查 | 进区 +1 命 |

区规通过 `enterZone()` 进区时应用，存续到下一个分区（`t: Infinity`），换区时由
`clearDistrictMods()` 清掉 —— 注意**不能**用 `clearMods()`，那会把玩家攒的卡牌一起删。

区规只改数值与生成器权重，**不改跳跃物理**，所以难度审计（`auditPattern` / `clearSpan`）
的结论对每个区仍然成立。密度调整走 `gapFor`，不缩短到低于反应时间下限。

## 二、事件（Events）

每隔一段距离触发一次，屏幕顶部弹出一张横幅：客串角色头像 + 标题 + 一行说明 + 效果。
持续型事件有倒计时，即时型事件立刻结算。

### 「换代级提升」这条的处理方式

用户明确定义过这个梗的**语义**：形容某次模型换代提升大到令人震惊失神、瘫坐在地。
字面出处（谁在何时说了「仿佛看到原子弹爆炸」）查不到 —— 中文搜索会把「奥特曼」
解析成特摄片，英文侧也没有可引的原话。因此这条按「社区梗」收录，在 `src` 字段里
如实标注为**字面出处未能核实**，不冒充通告。可以核实的相邻事实只有一个：
Altman 在 2023-05-16 参议院听证上引用 IAEA 模式主张国际监管，核类比确有其事，
但「原子弹爆炸」不是他的原话。

**写新条目时请沿用这个约定**：梗可以写，但 `src` 必须说清它是梗还是事实。

其余条目全部来自已核实事件。**弃用**：Llama 改名梗、「哀嚎的 GPU」（均查无来源）。

实装 13 条（含两条一正一反的分时事件）。每条在 `memes.js` 里的 `src` 字段是它
的现实依据，改文案时请连 `src` 一起看，别把有据的事写成段子、也别把段子写成通告。

## 三、卡牌（Cards）

每 5000m 停一次，抽 3 选 1，永久生效到本局结束。获得记录显示在选牌界面底部和
游戏结束卡的「本局改进」里。

池子（8 张）：白饭自由（白饭 ×1.5）、缓存命中（连击窗口 +1.2s）、
滑动窗口（二段跳 +12%）、开源权重（道具时长 ×1.4）、价格屠夫（分数 ×1.2）、
基座模型（立即一层防火墙）、合规豁免（+1 命）、分时电费（白饭 ×2 + 立刻吸附全场）。

每张牌的 `icon` 是**相对 `assets/` 的完整路径**（图标分散在 `item/` 与 `ui/` 下）。

## 四、里程碑

每 1000m 一次轻量反馈（飘字 + 音效），关键节点给卡牌。
记录最远距离到 localStorage。

## 五、客串角色

六位同人形象（DeepSeek / Qwen / 智谱 / Claude / GPT / Gemini 娘）位于 `image_形象/`，
由 `tools/prep_mascots.py` 输出到 `assets/mascot/`：全身立绘（`<id>.png`，168px 高）
与方形头像（`<id>_face.png`）。用途：事件横幅头像。

**处理方式（走过一段弯路，记下来以免重复）**：最初试图直接给原立绘抠图。六张图情况
各异 —— 平白底、渐变底、带光带的地板、白色角色配白底，其中一张还是群像的裁切（边缘
带进了别的角色）。测地洪泛 + 连通域筛选试了三轮仍不稳。最终改为**以原图为参考重新
生成标准素材图**（统一姿势、纯色抠像底、不触边），再对产出做色键 —— 模型直接返回了
带 alpha 的图时连色键都省了。这条路一次就干净了：**能重画就不要抠图。**

本作沿用自研立绘，不直接使用该形象。

## 六、实现边界

- `src/memes.js` 纯数据，不含逻辑，方便后续增删条目。
- `src/game.js` 新增 zone / event / card / milestone 四套系统，全部由既有 `update()`
  循环驱动，不引入新的帧循环。
- 分区图层与角色图都是**可选资源**：缺图时分区回退到原生背景、头像隐藏，不阻塞启动。
  代价是文件名写错也会静默降级，所以 `auditZoneArt()` 在启动时把缺失项打进 console。
- 卡牌选择用独立的 `draft` 状态而不是复用 `paused`：暂停卡住在 `#overlay` 里，
  而 `#overlay` 盖在 `#hud` 之上，复用会把选牌界面埋掉。

### 「选卡时不能还在跑」

冻结模拟（`update()` 提前 return）本身不够 —— 视觉上仍像在跑，因为三件事没停：

1. `worldT` 还在累加，白饭和障碍继续上下浮动、速度线继续走；
2. 主角被定格在跑步循环的某一帧，看起来就是"跑动中被冻住"；
3. 场景没有任何视觉降级，卡片面板浮在一个看起来很活的画面上。

对应改法：`worldT` 只在非冻结状态下累加；`heroFrame()` 在非 `playing` 状态下返回
`idle`（空中则保持定格，那本来就是合理的定格帧）；选牌/暂停时给 `#stage` 加
`selecting` 类，把 canvas 做 `saturate(.35) brightness(.55)` 去色压暗。另外加了一个
「⏸ 已暂停」徽标和一行「已跑 Xm · Y 分 · 白饭 Z · 当前分区」，让它读起来像一次
检查点而不是一个悬浮菜单。

顺带补掉一个同源问题：`jumpPressed()` 原来无条件写 `player.buffer`，于是面板打开时按
空格会把跳跃存下来，卡片一点就自己蹦一下。现在只在 `playing` 状态下才缓冲
（键盘与触摸两条输入路径都加了同样的判断）。

**验证**：
- 选牌打开后的 1.2 秒内采样，`camX / dist / score / runT` 增量全部为 0，`selecting`
  类在位；点击卡片后 `dist` 恢复增长、`selecting` 被清掉。暂停键走同一路径，同样
  冻结、同样恢复。
- 在面板上连按 4 次空格再点卡片，落点为 `jumps: 0 / onGround: true / y: 600` ——
  没有凭空起跳。
- 连续多局实跑中统计不变量：`playing` 状态下 `selecting` 残留 0 次、
  选牌中未上色 0 次、异常 0。

### 复核（不完整，见下）

启动过一个独立复核 agent 专门查"工具与游戏的常量是否已经漂移"和"有没有被静默丢弃的
效果标签"，但它 15 轮预算耗尽、**没有给出结论**，所以这两项由我手工补测：

- **常量漂移**：逐项比对 `verify_balance.py` 与 `game.js`，`BASE_SPEED / MAX_SPEED /
  RAMP_DIST / GRAVITY / FALL_MUL / DJ_RISE_G / DJ_FALL_MUL / PLAYER_BOX_W /
  TIER_START` 全部一致。两处看似不一致、实为约定差异：
  `JUMP_V` 工具侧写 `1020.0 # magnitude`（游戏侧是 `-1020`，用 `JUMP_POWER = -JUMP_V`
  取模），`CLEAR_SLACK` 在工具侧叫 `SAFETY = 30  # must match CLEAR_SLACK in src/game.js`。
  两处都有注释点明对应关系，数值本身相同。
- **标签词汇**：把 `memes.js` 里所有 `eval`/`rule` 的键（18 个）与 `game.js` 的
  `INSTANT_TAGS`（10）+ `KNOWN_MULT`（8）对表，并额外检查 `fireInstantTag()` 是否真的
  有对应分支（避免"登记了但没实现"这种更隐蔽的静默丢弃）。三项均为零缺口。

**仍未验证的部分**：这两项之外，复核 agent 原本还要查的分区可达性、卡牌不被区规清空、
`applyEval` 返回值契约一致性等，没有独立结论。它们目前只有我自己的实跑与阅读作为证据。

### 两个"不公平"的修正

实现中途发现两处会把"玩笑"变成"白送伤害"，都改掉了：

1. **静默上传的遮挡层**原本接近不透明（0.72）。事件触发时场上可能已经有一个必须滑铲
   的低空障碍，全遮挡等于无法躲避。现在降到 0.40、用 mask 在角色所在车道切出clear
   window，只作为"视线税"，仍然烦人但可读。
2. **地区限制事件生成的闸门**绕过了 `auditPattern()`（它只审计 `extendLevel()` 里批量
   生成的编排），直接落在既有障碍上会拼出一个无解组合。现在生成前会向前寻找一个两侧
   各留 260px 空地的位置再放。

### 验证记录

- `tools/verify_balance.py`：把 `gapMul` 的下限作为新的第 2b 节写进工具，证明最密的
  事件密度下满速二段跳仍砸不进下一组障碍。下限取 0.88（真实安全边界约 0.82，
  留出余量），`game.js` 的 clamp 与该常量必须同步修改。
- 浏览器实跑（Edge + 脚本自动驾驶）：连续跑完五个分区、100km+，触发全部事件类型、
  取 9 张牌，`console` 零异常、零 `[level]` 警告；游戏结束卡显示分区与"本局改进"，
  重开正常。
- 实跑期间抓到并修掉的真实缺陷：`hasTag` 重构后漏定义（每次 `updateContentHud`
  抛异常）、纯即时效果卡牌往 `mods.perm` 塞 `null`（此后所有倍率读取崩溃）、
  `magnet` / 分区 `lifeAdd` 两个标签因不在 `INSTANT_TAGS` 而被静默丢弃、
  分区远/中景图层键写成 `bg/zone/` 而加载器用 `bg/zones/`（被"缺图优雅降级"掩盖，
  靠截图发现）。最后一项促成了 `auditContentTags()` 与 `auditZoneArt()` 两个启动期
  自检。
