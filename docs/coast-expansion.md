# 夕阳海岸公路扩展

扩展接入实际运行的 `src/game.js`。`src/coast.js` 管理夕阳美术，`src/route-patterns.js` 管理城市与夕阳共用的随机排列；未接入的 `src/districts.js` 草稿不影响游戏。

## 六分钟城市长跑

首次进入夕阳公路设在 **360 秒有效跑步时间**，处于要求的 5–7 分钟范围。暂停、商店、标题、结束与命中停顿不计时；冲刺、加速事件及掉落救援推进距离不会提前触发。以时间判断夕阳入口，距离仍用于计分、速度和原分区的最低推进条件。

| 城市内分区 / 新场景 | 最早有效跑步时间 | 节奏 |
| --- | ---: | --- |
| 语料海 | 0:00 | 熟悉基础跑跳和收集 |
| 榜单擂台 | 0:50 | 平台、短空洞与路线选择 |
| 开源市集 | 1:50 | 连续障碍和多段平台 |
| 算力金库 | 3:00 | 交替动作与复杂路线 |
| 合规边境 | 4:20 | 城市后段综合挑战 |
| 夕阳海岸公路 | 6:00 | 延续难度，增加复合组合权重 |

原城市分区同时保留原距离条件。随机排列难度分五档，除距离门槛外，分别至少经过 25、70、140、230 秒才升级，避免速度增长让复杂组合过早全部解锁。

5:52 提示前方夕阳公路。5:52–6:08 新生成的排列优先采用收集物喘息路线，进入前后十秒不启动新的随机事件。已在前方生成的路线继续正常滚动，不突然删掉障碍。背景、赛道表面和主题障碍以 **4.8 秒渐变**接入，保持操控与碰撞连续。生成提前量会影响喘息路线实际到达玩家的位置。

## 共用随机排列

保留原有排列，增加 15 类：

- 空洞与云岛：高低错落云岛、阶梯云岛、谷形云岛、连续短断路、短空洞接平台桥。
- 平台路线：上行阶梯、高低交替平台、上层平台与地面跳跃分路。
- 复合障碍：空洞接落地后障碍、连续随机地面障碍、随机顺序跳跃/滑铲、移动巡逻障碍串。
- 收集物：扇形、上下波动双路线、双弧线白饭排列。

数量、宽度、间距、高度、障碍种类、移动幅度及收集物轨迹在模板约束内随机。平台上的奖励跟随实际随机后的平台表面；空洞落地后预留反应空间。

调度器避开最近五种排列，尽量避免同类连续三次，最多四组挑战后插入奖励喘息段，并降低已频繁出现排列的权重。两种场景都提高平台和空洞出现机会；夕阳额外提高复合动作与空洞权重，继续沿用原玩法和道具。

新空洞与云岛的几何间距按现有最强减速事件（0.7 倍）预留，并检查 1 倍与 1.45 倍速度下的跳跃路径。组合随机性受可达性和反应距离限制。

## 统一美术与动态背景

夕阳背景、前景公路材质、远处自行车桥和骑车鹈鹕保持统一美术风格。鹈鹕位于背景桥，鲸鱼娘在独立的前景碰撞赛道上跑酷。自行车辐条与曲柄旋转、身体颠簸、音符、海面闪光和灯塔光束继续播放。

巡逻障碍使用清扫机器人外观，晶体使用施工路障，地雷使用路锥，低空障碍使用海鸥；保持原尺寸、碰撞箱、运动及跳跃/滑铲/冲刺/下砸规则。浮空平台、白饭与其他收集物、道具、商店、连击及随机事件均共用原系统。

## 游戏素材

imagegen 生成的背景、赛道、障碍图集与骑车鹈鹕源素材保存在 `raw/coast/`，成品位于 `assets/coast/`。这些是供游戏分层合成的素材，无 HUD 或玩家界面。`tools/build_coast_assets.py` 负责裁切、缩放和格式转换，保留透明通道。未使用的金贝壳与潮汐晶体保留为素材库，游戏不加载。

具体提示见 [coast-art-prompts.md](coast-art-prompts.md)，素材来源见根目录 `ASSET-LICENSE.md`。本轮排列扩充复用已有美术。

## 验证与范围

- `node --check src/game.js`、`src/coast.js`、`src/route-patterns.js`：语法检查。
- `python tools/verify_balance.py`：原物理平衡数值审计。
- `node tools/verify_routes.cjs`：3,700 组随机排列，11,100 组速度条件检查，覆盖新增空洞/平台路线可达性、地面障碍跨度、随机变化及喘息段约束。结果见 `route-generation-verification.json`。
- `node tools/verify_coast.cjs`：浏览器长跑覆盖五个城市分区、六分钟入口、渐变、暂停/商店冻结、连续冲刺无法提前入场、新排列实际出现及运行时审计；检查 JavaScript 错误、素材请求失败和警告。结果见 `coast-verification.json`。
- 当前实机浏览器截图：`city-expanded-gameplay.png`、`coast-gameplay.png`。

浏览器长测用补充生命和无敌设置覆盖完整路程；几何检查使用简化跳跃模型。两者用于验证程序与路线约束，不能替代真人对难度、手感的试玩；实体手机触控尚未验证。测试使用本机 Playwright 与 Edge。
